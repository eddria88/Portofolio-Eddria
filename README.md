## 📖 Tentang Project

**Portofolio Eddria** adalah website portofolio pribadi yang dibangun menggunakan HTML, CSS, dan JavaScript murni — tanpa framework tambahan. Website ini dirancang untuk menampilkan profil, pendidikan, keahlian, proyek, pencapaian, dan informasi kontak secara elegan dan responsif.

---

## ✨ Fitur

- 👤 **Profile** — Perkenalan diri dan foto profil
- 🎓 **Education** — Riwayat pendidikan
- 🛠️ **Skills** — Keahlian dan teknologi yang dikuasai
- 🗂️ **Projects** — Showcase project-project yang telah dibuat
- 🏆 **Achievements** — Pencapaian dan penghargaan
- 📬 **Contact** — Informasi kontak dan form pesan

---

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| **HTML5** | Struktur dan konten halaman |
| **CSS3** | Styling, layout, dan animasi |
| **JavaScript** | Interaktivitas dan dinamisme |
